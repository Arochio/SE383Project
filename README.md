# SE383Project

## Clicker Empire

SE383Project is an incremental clicker game in which players build points by clicking a button and investing those points in upgrades. Each upgrade improves the player's progress by increasing the number of points earned per click or by generating points automatically over time.

Players can purchase upgrades such as Auto Clicker, Double Click, Click Frenzy, and Mega Farm. Upgrade costs increase with each purchase, encouraging players to balance short-term spending with long-term growth. Each game is associated with a player-specific identifier so progress can be retrieved between requests.

The project is organized as a frontend Razor Pages application and a backend ASP.NET Core API. The frontend displays the game state and handles player interactions, while the backend manages clicks, upgrades, points, and player state.
